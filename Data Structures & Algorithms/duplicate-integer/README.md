# Contains Duplicate

## Problem Description
Given an integer array `nums`, return `true` if any value appears more than once in the array, otherwise return `false`.

## Examples

**Example 1:**
```text
Input: nums = [1, 2, 3, 3]
Output: true
```

**Example 2:**
```text
Input: nums = [1, 2, 3, 4]
Output: false
```
